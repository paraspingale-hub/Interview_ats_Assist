An **Object-Relational Mapper (ORM)** is a tool or library that allows backend developers to interact with a relational database using object-oriented code (like Python) instead of writing raw SQL queries.

**How it helps a backend developer:**
1. **Translates Code to Database Tables:** It maps database tables to Python classes. For example, a `users` table becomes a `User` class, and a row in that table becomes an object of that class.
2. **Eliminates Raw SQL:** Instead of writing `SELECT * FROM users WHERE id = 1;`, you can simply write `User.objects.get(id=1)` (in Django) or `session.query(User).filter_by(id=1)` (in SQLAlchemy).
3. **Enhances Security:** ORMs automatically parameterize queries, which helps prevent SQL Injection attacks.
4. **Database Portability:** If you decide to switch your database from SQLite (for development) to PostgreSQL (for production), the ORM translates your Python code into the correct SQL dialect automatically. You don't have to rewrite your queries.
